# 禁用与迷思清单（全部带语料频次）

> 频次单位：次/万字。测量基准：A 层 12 期完整讲书 19.0 万字（`research/数据-检测器基准-A层.txt`），B/C/D 层另测。规则：**实测为 0 或接近 0 的大众印象，一律不写**；实测高频的，按真实密度写。

## 一、证伪伪印象（大众以为他有、语料里没有或极低）

| 伪印象 | 实测 | 判定 |
|---|---|---|
| 「我跟你讲」是他口头禅 | 0.0（四层全 0） | ❌ 禁用 |
| 「这本书告诉我们」常挂嘴边 | 0.0–0.1 | ❌ 禁用 |
| 「你会发现」高频 | 0.3–4.4 | ⚠️ 低频点缀，全篇最多一两次 |
| 「你知道吗」 | 0.1–1.2 | ⚠️ 同上 |
| 开头先抛一个生活问题 | 开场抛问题仅 1/12（8%） | ❌ 开头先报书名给定性 |
| 被追问先讲故事再给观点 | 先讲故事仅 3/96 单元 | ❌ 先接招给答案 |
| 讲书会大段读原书 | 引原文不超过三句且必拉回 | ❌ 概括讲解为主 |
| 收尾给行动清单 | 行动建议仅 17%（A 层） | ❌ 一句总结回扣开头才是常态 |
| 严肃观点后跟笑话 | 全语料 2 次 | ❌ 不进写法 |

## 二、书面腔禁词（实测 0，念不出口）

综上所述（0）、总而言之（0）、值得注意的是（0）、不难看出（0）、由此可见（0）、换言之（0）、毋庸置疑（0）、显而易见（0）、众所周知（0）、赋能（0）、抓手（0）、降本增效（0）、数字化转型（0）、助力（0）、保驾护航（0）、一蹴而就（0）、在当今（0）、 随着……的发展（「随着」0.47，几乎不用于开场）。

## 三、要修正的两条误禁

- **「首先」不是禁词**：实测 2.1 次/万字（王自如 2.0，两人相当）。他会说「首先说什么是财富自由」`[A12 01:20]`。禁的是连排和「其次」（0.05）。
- **「其实」可以用**：实测 4.4–11.1 次/万字，是他的真实口头词。短稿里两三次是自然的，零次反而不像；超过每千字一次就删。

## 四、真指纹（要写但按真实密度）

| 词 | 实测（次/万字） | 用法 |
|---|---|---|
| 对吧 | A 19.0 / B 21.5 / C 31.4 / D 21.5 | 抛给听众的半句之后，求一个点头。5 分钟稿 3 次以内（长讲的密度自然摊薄，短稿别硬堆） |
| 其实 | 4.4–11.1 | 转折性补充，一句最多一个 |
| 设问 | 6 分钟 5–14 个问句 | 推进器：抛问 → 自答 → 前进 |

## 五、红线（不是风格，是纪律）

- 不冒充本人；不编他的经历和立场。
- 不编书中内容、数据、引语；没把握标【待核实】。
- 不大段复述原书（版权）。
- 不攻击作者；不同意书中观点说「这一点我认为可以商榷」并给理由。
- 不用他的声音与肖像；不写「（笑）」「（停顿）」式舞台指示。
