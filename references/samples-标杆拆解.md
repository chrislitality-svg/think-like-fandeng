# 标杆拆解（两期完整讲书的骨架对照）

> 拆两期不同类型的 A 层样本：传记型（《我可能错了》，A11）和框架型（《财富方程式》，A12）。转写与编码本地可查（`research/编码-段落.csv`）。

## 一、传记型怎么讲（A11《我可能错了》66 分钟）

**骨架**：定性开场（100 秒）→ 作者生平按时间线推进（求学→辞职洗碗→失恋谷底→出家修行→还俗→患病）→ 每个人生阶段嵌一个书中的观点或比喻 → 患病段落情绪推到顶 → 定性收尾。

**可复用的手法**：

1. **旧书类比开场**：`[00:32]`「这本书让我想起来很多年前的一本畅销书叫《雪洞》」——用听众可能知道的旧书给新书定位。
2. **幽默调剂的节奏**：每个沉重段后接一个轻段。坠崖者喊上帝「放手」的笑话接在修行枯燥段后 `[27:13]`；「百事可乐是唯一要求」接在 500 公里苦行前 `[36:47]`；夫妻吵架「此刻我的曼陀罗是也许是你错了」接在曼陀罗正题后 `[30:39]`。
3. **金句物件化**：把书的要义放在一个具体物件上——抽纸桶上印的「知识为所知的一切而自豪 智慧为不知的一切而谦卑」`[26:53]`、婚戒内圈刻的「一切皆会过去」`[53:34]`。
4. **自曝印证**：讲僧团磨合时插自己「年轻时出差两三人一间觉得正常，现在难受」`[19:27]`——书里的道理用我的变化印证。
5. **结尾定性不总结**：不重复要点，给这本书一个身份——「千万不要把它当作一个开悟者的开悟之书……这是一本慈悲的书」`[66:01]`。

## 二、框架型怎么讲（A12《财富方程式》59 分钟）

**骨架**：定性开场 → 给出全书公式（专注+自律×时间×分散投资）→ 按公式四要素逐一展开 → 每个要素内部「品格/观点 → 故事 → 操作建议」→ 回扣公式收尾升华。

**可复用的手法**：

1. **公式先行**：`[02:01]` 先把全书的框架一句话给出，之后每一段都能挂回公式——听众任何时候走神都能归位。
2. **自述选书动机**：`[22:02]`「接下来这一条是我认为 我就是我讲这本书的最重要的一个原因」——明示这本书打动他的那一点，替听众建立期待。
3. **数据进故事**：`[18:56]`「调查了 233 位百万富翁 86% 的人每周工作的时间超过 50 个小时」——数据说完立刻接「工作是我们的福利啊各位」的口语化感叹，数据不冷场。
4. **往期书目回环**：《纳瓦尔宝典》《第三个千年思维》《为什么伟大不能被计划》《低风险创业》——同一话题的书互相印证，形成「书网」。
5. **升华回扣**：`[57:55]` 讲完全部赚钱方法后收在「我们生命的意义 是让我们能够有更多的时间 去陪伴我们所爱的人」——把俗题收回人话。

## 三、两期共通的节奏

- 每个观点段后必有场景或故事跟上（探索性结论，定性可靠）。
- 「你」的出现密度稳定：整期听下来每隔一两分钟就有一次直接对听众说话。
- 收尾都是「一句定性/总结 + 祝愿 + 谢幕」，不列行动清单。
