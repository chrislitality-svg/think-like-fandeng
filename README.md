# 像樊登一样讲书（think-like-fandeng）

一句话：把一本书、一个道理，讲成樊登那样——**先报书名再讲理，观点永远挂着故事，随时把「他」换成「你」**。这是一个装进 AI 工具的 skill，你说一句话，它按樊登讲书的方法产出内容。

## 看效果

**你说**：「用樊登的方式，给我讲讲《被讨厌的勇气》。」

**它给你**（节选）：

> 为什么说它可能得罪你呢？因为这本书的核心观点，就是要拿掉你手里那把伞。
>
> 什么伞呢？我们每个人心里都装着一堆「因为所以」。因为我不善言辞，所以我搞不好人际关系；因为我原生家庭不好，所以我现在过得不幸福。阿德勒说，不是这样的。他提出一个概念，叫做「课题分离」。
>
> ……孩子不学习，着急的是谁？是你。但是不好好学习这件事的后果，最后落在谁头上？是孩子。那这就是孩子的课题。你可以把鞋擦干净了放在门口，愿意上学的孩子，他自己会穿上鞋走出门。

**你说**：「这是我的读书分享稿，樊登帮我改改。」

**它先指出**：通篇没有一个「你」，观点后面全是概念没有故事——然后给你改好的全文，附三条改动说明。

更多示例（12 个，覆盖全部五种用法）→ [examples/](examples/)

## 怎么用

把 [SKILL.md](SKILL.md) 装进你的 AI 工具（支持 Claude Skills / ZCode skill 的工具直接安装），然后：

| 你说 | 你得到 |
|---|---|
| 用樊登的方式，给我讲讲《XXX》这本书 / 这一章 | 5 分钟可直接念的讲书稿 |
| 用樊登 skill 帮我分析一下 XXX | 可转发的分析短文 |
| 用樊登的方式写一篇 2 分钟口播 | 可直接念的稿子 |
| 我想和樊登聊聊 XXX，你来当樊登 | 一来一回的对话（第一轮声明：按他的思路聊，不是本人） |
| 这是我的讲稿，樊登帮我改改 | 最要紧的问题 + 改好的全文 + 改动说明 |

没有 skill 机制的工具，直接把 SKILL.md 全文粘给 AI 当系统提示词，也能用。

## 这套方法是从哪来的

不是「感觉像」，是数出来的：我们下载了樊登公开的讲书与访谈内容（60 个样本、约 30 小时），逐句转写后切成 786 个意义单元编码统计——

- 开场 75% 先介绍书和作者，不是先抛问题；
- 79% 的观点后面紧跟一个有人物有动作的故事；
- 81–91% 的段落直接对「你」说话；
- 被追问时 61–84% 第一句就给答案，先绕圈讲故事的只有 3 次；
- 收尾以一句总结为主，堆行动建议的只有 17%；
- 一口气（逗号之间）中位 7–9 个字。

完整研究方法、每条结论的原文出处与出现比例 → [METHODOLOGY.md](METHODOLOGY.md) 和 [references/thinking-思维运转.md](references/thinking-思维运转.md)。

## 版权与伦理

- 研究只用公开免费内容；转写全文与音频不公开。
- 本工具产出为**风格学习**，不冒充樊登本人；对谈用法第一轮即声明。
- 讲书稿只概括和讲解，不大段复述原书；书中事实无把握时标注【待核实】。
- 不使用其声音与肖像；不攻击任何作者。
