# 编码规则 v1（编码前存档）

> 本文件在编码开始前存档，编码过程中不修改。确需修改：记录原因与日期，已编部分按新规则重编。
> 内容照抄《02-分析方法与编码手册》第三、四、五节，补充各层对应关系与操作细则。存档时间：2026-10-24。

## 〇、层与分析单位对应

| 层 | 分析单位 | 切法 | 输出文件 |
|---|---|---|---|
| A 完整讲书（10 期） | 语义段 | 按「这段在讲一件事」切，一期 10–25 段；话题明显换了、或开始新故事/新观点就切 | 编码-段落.csv |
| B 官方短视频（28 条） | 整条 | 1–5 分钟一般 1–4 段；只有需要拆时才拆段 | 编码-段落.csv（每条至少一行） |
| C 演讲（6 场） | 语义段 | 同 A；多嘉宾场次只编樊登部分，他人部分在整体表「他本人说话时长」扣除 | 编码-段落.csv |
| D 被采访（6 场） | 应答单元 | 一个问题 + 他对这一问题的完整回答，到下一个问题为止 | 编码-应答单元.csv |
| E 第三方切片（8 条） | 应答单元（有问答）/整条（无问答） | 只用于和 D 层对照剪辑偏差 | 编码-应答单元.csv（无问答的按整条一行登记） |

每期/每条先在 `编码-整体.csv` 登记一行（4.1 节字段，A/B/C 层；D/E 层只填可判定项）。

## 一、每期/每条整体登记（4.1）

| 列 | 填什么 | 判定规则 |
|---|---|---|
| 开头前 30 秒在做什么 | 抛问题 / 讲故事 / 介绍书和作者 / 说一个数据 / 说一句结论 / 寒暄 / 其他 | 看前 30 秒里第一个完整意思；有片头预告（把后面的话剪到前面）的，标「预告」，再看预告之后 |
| 第一次提到书名的时间 | 时间点 | 精确到秒 |
| 书的原顺序和讲的顺序 | 是否重新排列；排列依据 | 只用公开的书籍目录比对；拿不到目录就填「无法判断」 |
| 结尾在做什么 | 行动建议 / 一句总结 / 回到开头的问题 / 推荐读原书 / 其他 | 看最后一个完整意思 |
| 总时长、他本人说话时长 | 秒 | |

## 二、语义段编码（4.2，A/C 层必填，B 层可选）

| 列 | 填什么 | 判定规则 |
|---|---|---|
| 段号、起止时间 | | 必填，起止时间来自转写 |
| 这段在讲什么 | 一句话 | 必须能在原文里指到对应的话，不许写原文没有的概括 |
| 和上一段的关系 | 回答上一段留下的问题 / 给上一段举例 / 转折 / 新起一个并列的点 / 接不上 | 说不出「它接着上一段的什么」，就填「接不上」 |
| 内容来源 | 书里的观点 / 书里的例子 / 他自己的经历 / 他身边人的事 / 听众或用户的案例 / 研究或数据 / 比喻 / 笑话 / 其他 | 可多选，按占比最大的排第一。有「书里讲」「作者说」这类提示的算书里；用「我」讲亲历的算他自己；判断不了填「不确定」 |
| 有没有把抽象说法落到具体场景 | 有 / 没有；场景类别：家庭 / 孩子 / 伴侣 / 职场 / 自我 / 社会 / 其他 | 抽象说法 = 概念、原则、结论；具体场景 = 有人物、有动作、有对话的情境 |
| 直接对听众说话 | 有 / 没有；形式：对「你」说 / 提问 / 让听众想象 / 让听众做个动作 | |
| 段内结论句 | 原话 | 没有就填「无」 |
| 备注 | 反例、拿不准的地方 | |

## 三、应答单元编码（4.3，D/E 层）

| 列 | 填什么 | 判定规则 |
|---|---|---|
| 单元起止时间、提问原话 | | 提问听不见的（转写里只有回答），标「提问不可见」 |
| 问题形式 | 是非问 / 开放问 / 挑战质疑 / 求建议 | 是非问 = 能用「是 / 不是、能 / 不能、该 / 不该」回答 |
| 第一句在做什么 | 给答案 / 讲故事 / 反问 / 先共情 / 复述问题 / 引用一本书 / 其他 | 第一个完整小句 |
| 支撑方式 | 同语义段「内容来源」 | 可多选 |
| 有没有转到某本书 | 有 / 没有；书名 | |
| 有没有让步或分情况 | 有 / 没有 | 明确承认例外、对不同人给不同答案，算有 |
| 收尾在做什么 | 行动建议 / 一句通则 / 一个比喻 / 回到开头 / 被打断 / 其他 | |

## 四、句子层（4.4，抽样）

从 A 层随机抽 4 期（随机种子 42），每期取开头 3 分钟和中段 3 分钟，只加标点不改字，存 `research/句子层-标点版/`（不公开全文）。统计口径：句长分布（中位数、>30 字比例）；逗号间长度；连接词每千字次数；提问句占比；对「你」说话次数。分母 = 剔除时间戳、元信息、空白、他人说话后的字数。

## 五、口头习惯词（4.5，低权重）

候选词表（先列定再数）：「你会发现」「我跟你讲」「这本书告诉我们」「其实」「对吧」「好吧」「你知道吗」。分母同上。按层分别报告 + 每期差异范围。

## 六、编码纪律（手册第五节）

1. 全部单元都编，不能只编代表例子。
2. 每个单元写起止时间，能回放核对。
3. 拿不准填「不确定」；某列「不确定」占比 >15%，回头改规则并全列重编。
4. 规则没覆盖的情况记备注，不临时发明类别。
5. 编码表存 CSV，配脚本转可读 Markdown。

## 七、操作补充（不改规则本身，只定流程）

- 分说话人：无 pyannote 凭证，D 层与多嘉宾 C 层的说话人边界按文本结构判别（问答轮转、称呼、内容线索），在整体表「他本人说话时长」标注为「文本估计」，错字率报告里说明该方法局限。
- 编码由 AI 执行：每单元编码时必须同时给出转写原文对应行号区间，便于复核 agent 只读转写独立校验。
