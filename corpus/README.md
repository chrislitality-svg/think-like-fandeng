# corpus/ 语料说明

本目录存放转写产物的元信息。**转写全文默认不公开**（见《01-项目方案.md》第五节）：

- 音频文件只存在本地 `research/scripts/audio/`，不提交；
- 转写全文（`*.txt`、`*.words.json`、`*.paraformer.txt`）只在本地分析用，不提交到公开仓库；
- 公开仓库中只包含：`research/data/样本.csv`（样本清单与链接）、编码表、每处一两句的短引用（注明编号与时间点）。

## 转写参数

- 主转写：faster-whisper large-v3，int8 CPU，`language="zh"`，VAD 开启，`beam_size=5`，逐词时间戳开启。
- 每个文件头四行是元信息（标题、来源链接、层与发布日期、参数），正文每行 `[分:秒] 文本`。
- 字数统计口径：**分母一律剔除 `#` 开头元信息行、时间戳方括号、空白**；多说话人样本另剔除他人说话部分（说话人判定方法见《research/编码规则-v1.md》第七节）。

## 文件对应

58 条样本的编号、来源、链接见 `research/data/样本.csv`。编号规则：A01–A10 完整讲书、B01–B28 官方短视频、C01–C06 演讲、D01–D06 被采访、E01–E08 第三方切片（只做对照）。
