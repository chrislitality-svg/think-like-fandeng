# research/ 研究过程与数据

- `data/` 公开内容清单（账号全量投稿列表）、样本清单（样本.csv）、抽样日志（种子 42，脚本可复跑）
- `编码规则-v1.md` 编码前存档的规则（手册第三至五节）
- `编码-整体.csv` `编码-段落.csv` `编码-应答单元.csv` 全量编码表（60 样本、786 单元）
- `编码笔记.md` 反例与规则缺口
- `统计结果.md` 全部统计（stats.py 一键复算）
- `复核报告.md` 第二人复核一致率与 kappa
- `转写质量报告.md` 错字率估计（双模型对比）与混合引擎说明
- `句子层-标点版/` 句子层抽样（本地，不公开全文）
- `scripts/` 抽样、下载、转写、编码合并、统计、复核、检测器基准全套脚本

## 不入库的内容

音频文件、转写全文（含 *.txt / *.words.json / *.paraformer.txt）、编码切片中间产物（编码输出/、复核编码/）。见根目录 .gitignore 与方案第五节。
